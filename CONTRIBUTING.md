# Contributing to RemoteOS

Thank you for your interest in contributing to RemoteOS! 🎉

## How to Contribute

### 1. Fork & Clone

```bash
git clone https://github.com/YOUR_USERNAME/remoteos.git
cd remoteos
```

### 2. Create a Branch

```bash
git checkout -b feature/amazing-feature
```

### 3. Make Changes

- Follow the existing code style
- Add tests for new features
- Update documentation if needed

### 4. Test

```bash
pnpm test
pnpm typecheck
pnpm lint
```

### 5. Commit

```bash
git commit -m "feat: add amazing feature"
```

Use [Conventional Commits](https://www.conventionalcommits.org/):
- `feat:` — New feature
- `fix:` — Bug fix
- `docs:` — Documentation
- `style:` — Formatting
- `refactor:` — Code restructuring
- `test:` — Adding tests
- `chore:` — Maintenance

### 6. Push & PR

```bash
git push origin feature/amazing-feature
```

Then open a Pull Request on GitHub.

## Code Style

- TypeScript with strict mode
- ESLint + Prettier for formatting
- Meaningful variable names
- Comments for complex logic

## Reporting Issues

- Use GitHub Issues
- Include steps to reproduce
- Include error messages
- Include your environment (OS, Node version)

## Questions?

Open a GitHub Discussion or reach out on Telegram.
